# SimulationLE / Science

科学计算案例档案，收录纵向 PET 摄取变化、层合材料热接触反演、空间糖酵解分配及 Donnan 双层凝胶四个案例。

首页提供搜索、领域筛选和详情入口。详情页包含科学问题、数据与假设、原生软件交付和结论的适用范围。图表为本站原创示意，展示相对形态和概念。

## 本地预览

在仓库根目录运行 `python3 -m http.server 8000`，打开 [localhost:8000](http://localhost:8000/)。站点由 HTML、CSS 和 JavaScript 构成。四个详情页分别位于 `cases/`，共享样式、图表和交互脚本位于 `assets/`。

## 发布

[GitHub Pages](https://cioutn.github.io/simulationle-science/) 从 `main` 分支的根目录部署。
